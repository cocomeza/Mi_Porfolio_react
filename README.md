## 📋 Descripción

Portfolio profesional desarrollado con React.js que muestra mis proyectos, habilidades y servicios como Desarrollador Web Full Stack, Community Manager y Tester QA.

## ✨ Características Principales

### 🎨 Diseño y UX
- **Tema Oscuro/Claro**: Sistema de temas con persistencia en localStorage
- **Diseño Responsivo**: Adaptado para todos los dispositivos
- **Animaciones Fluidas**: Implementadas con Framer Motion
- **Lazy Loading**: Carga optimizada de imágenes
- **Accesibilidad**: ARIA labels y navegación por teclado

### 📱 Secciones
- **Home**: Presentación con hero section animado
- **Sobre Mí**: Información personal y profesional
- **Servicios**: Catálogo detallado de servicios ofrecidos
- **Proyectos**: Portfolio con filtros por categoría
- **Habilidades**: Tecnologías y herramientas organizadas
- **Testimonios**: Carousel de testimonios de clientes
- **Contacto**: Formulario de contacto con validación

### 🛠 Características Técnicas
- **SEO Optimizado**: Meta tags y structured data
- **Google Analytics**: Tracking de eventos y métricas
- **Performance**: Optimización de carga y renderizado
- **PWA Ready**: Manifest y service workers
- **Formulario Netlify**: Integración con Netlify Forms

## 🚀 Tecnologías Utilizadas

## 📦 Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/cocomeza/portfolio.git
cd portfolio
```

2. Instala las dependencias:
```bash
npm install
```

3. Inicia el servidor de desarrollo:
```bash
npm start
```

4. Abre [http://localhost:3000](http://localhost:3000) en tu navegador

## 🔧 Scripts Disponibles

- `npm start`: Inicia el servidor de desarrollo
- `npm build`: Crea la versión de producción
- `npm test`: Ejecuta las pruebas
- `npm eject`: Eyecta la configuración de CRA (no recomendado)
